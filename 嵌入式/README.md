# 嵌入式

嵌入式主要学了单片机入门课，电机控制相关一点原理和代码，pid等
目前正在手搓机械臂

入门时间主要集中在大一上学期，11、12月左右的时间，后续零零散散在保持推进
上学期完整学习了江协科技的51单片机和stm32
假期后看了foc的实现，简单试了试一个无刷的位置速度闭环驱动
下学期进展较少
暑假受委托调了一个tt马达平衡车的pid（虽然没用上，但是学了一下双环串级pid）。
顺手学习了pcb的绘制方法，可以进行基础的画板了
后面接收了老师的灵足时代电机，开始简单学习can通信，机器人运动学，并开始制作demo稳步推进，截至目前（2026/8/15）留校结束第二天，三自由度机械臂demo模型打印完成并组装。目前暂时停止推进并开始整理资料

计划会主要记录机械臂的制作过程，计划会先整理单片机入门的资料，有关foc和pid，一个是实际用不上，应该只会出一个知识点的讲解，另一个是实际使用更重要，会多讲一些实际的使用还有一点拓展（用tt马达的调参做讲解，没留下调参视频，只能多讲一些过程和感悟了）。

学嵌入式的契机是高中刷到过用树莓派玩游戏，好奇就买了一块，结果不会用，吃灰了。上大学后想多了解了解我手里的这块板子，没想到就这么入门了。
