# 手搓机械臂

- 硬件条件：灵足时代robstride 05 关节电机 \* 10，启明欣欣 stm32F407ZGT6 \* 2，拓竹H2D 3D打印机。
- 需求：为无人机提供环境交互能力。
- 计划：主从联动，ros中转遥控。
