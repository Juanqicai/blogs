# 机械臂结构设计（构型与设计原则）

> 这篇讲**怎么选机械臂的构型**，而不是怎么画 SolidWorks。核心是几条：
> **什么构型容易解逆运动学、什么构型现在成熟、常见构型有哪些（SCARA、六轴、并联、直角坐标…）、不同需求对应什么设计方法。**
> 建模操作见 [其他/solidworks](../../其他/solidworks)；模型文件路径见文末。
> 上篇：[运动规划](./运动规划.md)。

## 0. 先想清楚"需求 → 构型"

设计机械臂**第一步不是画图，而是定需求**。需求定了，构型基本就定了。几条硬需求：

| 需求 | 影响 |
|---|---|
| **工作空间**（多大、什么形状） | 决定构型和臂长 |
| **负载**（抓多重） | 决定电机、减速器、刚度 |
| **速度/节拍** | 决定构型（并联快、关节型中等） |
| **精度** | 决定构型和刚度 |
| **自由度（要几个）** | 决定是几轴、末端能否任意姿态 |
| **要不要柔顺/人机协作** | 决定是否上阻抗/导纳 |
| **成本、可维护性** | 决定是否用成熟集成关节 |

一句话：**需求先于构型，构型先于结构。** 很多人上来就画图，画完发现空间/负载/自由度对不上，返工。

## 1. 常见机械臂构型（认识它们）

### 1.1 直角坐标 / 龙门（Cartesian / Gantry）
- **结构**：3 个**平移**关节，互相垂直（X/Y/Z）。
- **优点**：控制超简单（XYZ 直接映射）、刚性好、精度高。
- **缺点**：占地面积大、速度慢、灵活性差。
- **典型用途**：点胶、搬运、大工作空间精密作业、CNC 类。
- **求解**：**逆解是平凡的**（就是三个线性坐标），最好解。

### 1.2 SCARA
- **结构**：2 个**水平转动**关节（肩+肘）+ 1 个**竖直平移**关节（Z）+ 可选腕部转动。
- **名字**：Selective Compliance Assembly Robot Arm（选择柔顺装配机器人）。
- **特点**：**水平方向柔顺、竖直方向刚性**——天生适合"竖直插销"这类装配。
- **优点**：快、在水平面内简单、装配/拾放很成熟。
- **缺点**：只擅长水平面内工作，竖直工作空间小。
- **典型用途**：PCB 装配、平面拾放、插装。
- **求解**：平面二连杆 + Z，解析解，很好解。

### 1.3 关节型 / 六轴（Articulated / Anthropomorphic）
- **结构**：像人的手臂——肩（2~3 轴）+ 肘（1 轴）+ 腕（3 轴）。
- **优点**：灵活、工作空间大、通用性最强。
- **缺点**：控制复杂、负载受关节限制。
- **典型用途**：焊接、喷涂、码垛、通用搬运/操作。
- **求解**：**带球腕（腕部 3 轴交于一点）时能解出解析解**。

> **原型：PUMA 机械臂。** PUMA = Programmable Universal Machine for Assembly（可编程通用装配机器），1970 年代由 Victor Scheinman 在 Unimation 发明，工业六轴关节型的鼻祖，也是机器人学教科书的标准案例。
> 它是"**六轴 + 球腕 + 解析解**"的代名词：`底座(yaw) → 肩(pitch) → 肘(pitch) → 腕(3 轴)`，腕部 3 轴**交于一点**，满足 Pieper 判据，逆解有封闭解；位置与姿态解耦，先解肩/肘定位置、再解腕定姿态。几乎每本机器人学教材（如 Craig 的《机器人学导论》）都用 PUMA 的 D-H 参数表当例题。
> 我们这台就是**把 PUMA 的球腕砍掉的简化版**（只留位置，去掉姿态自由度）。

> **我们这台臂就是关节型的简化版**：3 个转动关节（转台 yaw + 肩 pitch + 肘 pitch），去掉腕部的姿态自由度，只做位置级的末端控制。所以它便宜、简单、好解，代价是不能任意调整末端姿态。

### 1.4 并联 / Delta
- **结构**：多个支链**并行**驱动同一个末端平台（Delta 三臂、Stewart 六杆）。
- **优点**：**速度极快、刚度高、精度高**，负载集中在平台上。
- **缺点**：工作空间小、逆解较复杂、有奇异点。
- **典型用途**：高速拾放（Delta）、精密定位（Stewart）。
- **求解**：并联机构逆解要解方程，通常比串联难，一般数值解或特化解。

### 1.5 球坐标 / 极坐标（Spherical / Polar）
- **结构**：2 个转动 + 1 个平移。
- 现在**不太常用**了，早期搬运/点焊用过，已被关节型取代。

### 1.6 冗余（Redundant）
- **结构**：自由度 > 任务所需（如 7 轴人形臂、蛇形臂）。
- **优点**：灵活、能避障、能绕奇异点。
- **缺点**：逆解**有无穷多解**，要额外优化；控制更复杂。
- **求解**：一般数值解 + 优化（最小范数、避障代价）。

> **原型：Franka Emika Panda**（现代七自由度协作臂，研究界/实验室很常见）。它和 PUMA 正好相反：**7 轴冗余**，逆解无穷多解，要靠优化挑一组；但换来的是灵活、能避障、能绕奇异点。**要"解析解"就学 PUMA，要"灵活/避障"就学 Panda。**

## 2. 什么构型"方便求解"（逆运动学好解）

这是设计时**最值钱**的一条：**构型选对了，逆解能写出解析式；选错了，只能上数值迭代。**

### 2.1 Pieper 判据（关键）
**如果机械臂有 3 个相邻的转动关节，其轴线交于一点，或相互平行，那么逆解存在解析解（封闭解）。**

- **球腕（spherical wrist）**：腕部 3 个转动轴**交于一点**，这是最经典的"方便求解"结构。它把**位置和姿态解耦**——先解位置（决定肩/肘），再解姿态（决定腕），逆解变成两块独立的小问题。
- **3 个平行轴**：像 SCARA 的肩+肘、我们臂的肩+肘，两轴平行，平面二连杆逆解就是余弦定理，非常好解。

### 2.2 小结：越"规整"越好解
- **轴相交或平行**（而不是斜置）→ 好解。
- **自由度少、不冗余** → 好解（DOF = 任务 DOF）。
- **位置与姿态解耦**（球腕）→ 好解。
- **关节轴正交/平行** → 数学形式简单。

> ⚠️ 我们这台臂的**真实**构型，关节 2 和关节 3 的轴**其实不是严格平行**的（URDF 里 J3 轴 `{0.179, 0, -0.984}` 有个小斜置角）。所以严格说它**不是"纯平面二连杆"**，逆解比理想情况复杂一点。**设计时如果想让逆解好写，尽量把相邻关节轴做成交于一点或平行。**

## 3. 什么构型"现在成熟"（工业主流）

| 构型 | 成熟度 | 主要用在哪 | 说明 |
|---|---|---|---|
| **6 轴关节型** | 极成熟 | 焊接、喷涂、码垛、通用搬运 | 工业机器人绝对主流 |
| **SCARA** | 极成熟 | 装配、平面拾放 | 专为"竖直插销"而生 |
| **直角坐标/龙门** | 很成熟 | 点胶、大空间搬运、CNC | 简单、精度高 |
| **Delta/并联** | 成熟 | 高速拾放、包装 | 快、刚，工作空间小 |
| **协作臂（人机）** | 渐成熟 | 人机共融、柔性作业 | 常带阻抗/导纳、碰撞检测 |

**设计启示**：除非有特殊需求，**优先选成熟构型**。成熟构型的控制、配件、案例都多，能少踩很多坑。我们**不是**为了"创新"而手搓，而是**学习和验证**才选了简单的 3 轴关节型。

## 4. 不同需求 → 不同的设计方法

| 需求 | 推荐构型 | 设计重点 |
|---|---|---|
| 平面拾放、插装 | SCARA | 水平柔顺、竖直刚性、Z 轴直线 |
| 通用搬运/焊接/喷涂 | 6 轴关节型 | 球腕、工作空间、负载 |
| 高速拾放（包装） | Delta/并联 | 轻量、高速、刚度 |
| 大空间精密 | 直角坐标/龙门 | 刚度、精度、行程 |
| 人机协作/柔顺 | 协作臂 | 阻抗/导纳、碰撞检测、轻量 |
| 重型负载 | 并联/重载关节 | 刚度、减速比、驱动 |
| 末端任意姿态 | 6 轴及以上 | 腕部自由度、球腕 |
| 只做位置级末端 | 3~4 轴关节型 | 简单、便宜、好解（我们这种） |

**设计方法**：定需求 → 选构型 → 定自由度 → 选关节/电机 → 算负载和力矩 → 画连杆（控制质心/刚度）→ 建运动学模型（验证可解）→ CAD → 样机 → 标定。

## 5. 设计流程（从需求到样机）

```
1. 定需求：工作空间 / 负载 / 速度 / 精度 / 自由度
2. 选构型：按上表匹配（SCARA / 6轴 / 并联 / 直角坐标…）
3. 定自由度：位置级还是姿态级（要不要球腕）
4. 选关节：集成关节（RS05）or 电机+减速器
5. 算力矩：重力补偿、负载、加减速 → 校核电机
6. 运动学建模：D-H 参数 → 验证 FK/IK 是否可解、是否在限位内
7. 连杆设计：控制质心（靠近转轴）、保证刚度、控制质量
8. CAD 建模：安装座、连杆、末端、线缆、装配
9. 样机：3D 打印 / 加工 → 装配
10. 标定：方向 / 零位 / 软限位 / 重力补偿系数
11. 控制联调：运动学 → 轨迹 → 阻抗/导纳 → 网络
```

**关键**：**第 6 步（运动学建模）不能省**。很多人画完图直接打样，结果装配起来发现逆解对不上、重力补偿是错的。**运动学/动力学模型和 CAD 必须一致**（我们通过导出 URDF 同步到控制模型）。

## 6. 我们这台臂的构型（落到具体）

- **构型**：3 自由度关节型，`转台(yaw) + 肩(pitch) + 肘(pitch)`，位置级末端控制。
- **为什么**：结构简单、便宜、**好解**（肩肘两轴近似平行→平面二连杆）、够学习/验证用。代价是不能调末端姿态。
- **电机**：灵足时代 RS05 集成关节 ×10（3 自由度 + 5 自由度 + 主从并联）。
- **末端**：3 自由度是简单末端；5 自由度是**齿轮齿条夹爪**（两种齿数齿轮增力 + 齿条转直线）。
- **控制**：主从并联用 UDP 互发位姿 + 虚拟弹簧-阻尼做柔顺联动（见 [阻抗&导纳控制](./阻抗&导纳控制.md)）。

## 8. 一句话总结

- **需求先于构型，构型先于结构。**
- 常见构型：**直角坐标（好解/精度高）、SCARA（装配）、6 轴关节型（通用主流）、Delta/并联（快/刚）**。
- **方便求解**：3 个相邻转轴交于一点（球腕）或平行（平面二连杆）→ 能写解析逆解。
- **成熟**：SCARA、6 轴、直角坐标、Delta。
- 我们这台：**3 自由度关节型（转台+肩+肘）**，简单、便宜、好解，位置级末端控制。
