# 阻抗 & 导纳控制

> 入门向。重点讲三件事：
> 1. **阻抗/导纳控制和"直接加电流"有什么不同**；
> 2. **力控和位控的区别**；
> 3. 这两者大概怎么实现（不深挖），最后**整理一套参数及其含义**。
> 结合我们的三自由度机械臂项目（`motor`）来讲，它其实用了一套"虚拟弹簧-阻尼"的阻抗思想。
> 上篇：[运动规划](./运动规划.md)。

## 0. 先建立一个直觉

普通电机控制是**"我让你转到 90°，你就转到 90°"**（位置控制）。但如果末端碰到墙、碰到人，它还是会硬顶，因为它只认位置误差。

**阻抗/导纳控制**是换个思路：**"我希望你表现得像一根弹簧加一个阻尼"**。碰到东西时，它会**"软"下来**——你推它，它给一个跟位移成正比的抵抗力，而不是死顶着不动。

- 这一招在**人机协作、拖拽示教、主从跟随、碰撞柔顺**里非常有用。
- 我们这台机械臂的**主从联动**就是靠这个：两块板互相"感受到对方的位姿差"，然后用一个**有界弹簧-阻尼**去拉近它们，实现了"你动它也跟着动、还带一点柔性"。

---

## 1. 直接加电流 vs 阻抗/导纳

### 1.1 直接加电流（力矩/电流模式）

电机驱动最底层就是"给多少电流（→力矩）"。**直接加电流**就是：

```
τ = τ_cmd        // 直接给力矩指令
```

- 优点：简单、直接、响应快，**完全由你决定输出多少力**。
- 缺点：**你完全不管位置**。给多少力矩，臂就按动力学被推到哪里，撞到东西就硬顶（因为力矩是常数，不会因为被挡住而减小）。
- 所以"直接加电流"其实是一种**纯粹的力控制**，但**没有"柔顺"能力**——它不知道什么是"轻推"、什么是"硬撞"。

> 我们项目的电机（RobStride RS05）**底层就是力矩/位置模式**，`SendMotionControl` 发的是 `(角度, 速度, kp, kd, 力矩)` 五个量。真正让它"柔顺"的，是**在力矩上加了一层阻抗模型**（见下面），而不是纯发电流。

### 1.2 阻抗控制（Impedance Control）

阻抗控制是在**力矩层面**建模，让机器人对外表现成"质量-弹簧-阻尼"系统：

```
τ = Kp·(q_d - q) + Kd·(q̇_d - q̇) + τ_feedforward
```

- 输入：**期望位姿 `q_d`**（你想让它在哪）。
- 输出：**力矩 `τ`**。
- 行为：位置误差越大，回拉力矩越大；速度差越大，阻尼越大。**就像一根弹簧拉着末端回到目标点。**
- 关键：**它是"从位姿到力"**。给定一个位置，算出需要的力。所以它**最自然、也最容易**在"位置控制的电机"上实现（你本来就有位置反馈）。

### 1.3 导纳控制（Admittance Control）

导纳控制反过来：**输入力/力矩，输出位置修正。**

```
Δq 由外力/力矩积分而来      // 你推它，它就"让"一点
q_cmd = q_desired + Δq
```

- 输入：**外力/力矩 `F`**（通常用**力传感器**测，或者测电流反推）。
- 输出：**修正后的位置指令 `q_cmd`**，再交给一个位置控制器去执行。
- 行为：**"你用力推，它顺着走"**。
- 适合：**已经有"力/力矩传感器"**、或者电机是**位置模式**（不能直接给力矩）的场合。

### 1.4 两者区别一张表

| | 阻抗（Impedance） | 导纳（Admittance） |
|---|---|---|
| 因果关系 | **位置 → 力** | **力 → 位置** |
| 输入 | 期望位姿 | 外力/力矩 |
| 输出 | 力矩指令 | 位置修正 |
| 前提 | 能发**力矩**（力矩/电流模式） | 能测**力**（力传感器/测电流） |
| 感受 | 更"硬"、响应直接 | 更"软"、需要传感器 |

> 一句话：**阻抗是"你拽它，它给力"；导纳是"你推它，它让位"。** 物理上两个是同一个"弹簧-阻尼"模型的两种因果方向。

## 2. 力控 vs 位控（再补一句）

| 控制 | 控制量 | 目标 | 特点 |
|---|---|---|---|
| **位控** | 位置/角度 | 让末端精确到达某位置 | 刚性、不碰软；碰到东西会硬顶 |
| **力控** | 力/力矩 | 让末端输出某大小的力 | 柔性；但位置可能飘 |

- **位控**：只关心"到没到"，不管"用了多大力"。
- **力控**：只关心"出了多少力"，不管"在不在那"。
- **阻抗/导纳**是**介于两者之间**的"混合"思路：**既想控制位置，又想控制力，还用"弹簧-阻尼"把两者连起来**，让系统在"被挡住"时自然变成力控（力随位移增大），在"没有阻力"时表现为位控（回到目标位姿）。这就是为什么它们常被叫"柔顺控制"。

## 3. 本项目怎么实现的（简单过一遍）

我们项目里没有用完整的 6 自由度阻抗/导纳公式，而是**在力矩通道上叠加了几个"柔顺项"**，思想一致但更工程化：

1. **主从耦合（双侧力反馈）**：两块板互相发对方当前位姿，每块板把**虚拟位置**取成两边的中点：
   ```
   q_virtual = (q_local + q_peer) / 2
   τ_coupling = Kp·(q_virtual - q_local) + Kd·(q̇_virtual - q̇_local)
   ```
   然后限幅。这样**任意一边都能带头**，两边会互相拉近——这就是阻抗/导纳思想（一个对称的虚拟弹簧-阻尼）做**主从联动**。
   （代码在 `RobStride_App_ApplyPeerState`，`App/MotorApp/robstride_app.cpp`。）

2. **虚拟墙（软限位）**：当末端到达软限位边界时，只施加**向内**的力矩，抵抗继续往外跑，但**绝不把对侧拽过界**：
   ```
   上界: τ = -Kp·(q - max) - Kd·q̇   (只允许负)
   下界: τ = -Kp·(q - min) - Kd·q̇   (只允许正)
   ```
   （`virtual_limit_wall_torque()`。）

3. **重力补偿**：静态重力力矩单独算出来加进去（`GravityCompensation_Compute`），让臂在"松手/零力矩"时也能吊住，不至于掉下来。

4. **限幅 + 缓升（slew limit）**：所有力矩项（反射力 + 虚拟墙 + 上位机力矩）汇总后，过一个**总力矩限幅**和一个**时间上的变化率限幅**，避免突变：
   ```
   τ_final = clamp(τ_desired, -τ_limit, +τ_limit)
   τ_final = clamp(τ_final, τ_prev - slew, τ_prev + slew)   // 每步最多变化这么多
   ```
   （`limited_output_torque()`。）

> 所以说：**我们不是"直接加电流"，而是"加电流 + 一层阻抗/导纳模型（虚拟弹簧-阻尼 + 虚拟墙 + 重力补偿）+ 严格的限幅"**。这就是"柔顺"的来源。

## 4. 参数整理与含义

参数都来自 `App/conf/netconfig/net_common.h`（两块板共用）和 `App/conf/motor_conf.h`。单位统一为：角度 **rad**，力矩 **Nm**，速度 **rad/s**。

### 4.1 主从耦合（虚拟弹簧-阻尼）

| 宏 | 值 | 含义 |
|---|---:|---|
| `NET_REALTIME_BILATERAL_KP_NM_RAD` | `1.0` | 弹簧刚度：位置差 1 rad 产生 1 Nm 的回拉力 |
| `NET_REALTIME_BILATERAL_KD_NM_S_RAD` | `0.08` | 阻尼系数：速度差产生的阻尼力矩 |
| `NET_REALTIME_BILATERAL_TORQUE_LIMIT_NM` | `0.50` | 耦合力矩的最大值（限幅），防止互相顶太猛 |
| `NET_REALTIME_BILATERAL_MAX_ERROR_RAD` | `0.60` | 位置差超过它视为"失稳"，持续超时则**解耦** |
| `NET_REALTIME_BILATERAL_MAX_SPEED_RAD_S` | `3.00` | 任一侧速度超过它也视为失稳 |
| `NET_REALTIME_BILATERAL_UNSTABLE_TIMEOUT_MS` | `500` | 失稳需持续这么久才解耦（防单包误判） |

### 4.2 虚拟墙（软限位）

| 宏 | 值 | 含义 |
|---|---:|---|
| `NET_REALTIME_LIMIT_WALL_KP` | `3.0` | 软限位处弹簧刚度（比耦合更"硬"） |
| `NET_REALTIME_LIMIT_WALL_KD` | `0.10` | 软限位处阻尼 |
| `NET_REALTIME_LIMIT_WALL_MAX_NM` | `0.5` | 虚拟墙最大力矩 |

### 4.3 总输出限制

| 宏 | 值 | 含义 |
|---|---:|---|
| `NET_REALTIME_OUTPUT_TORQUE_LIMIT_NM` | `1.00` | **所有力矩项**（反射+墙+上位机）的总限幅 |
| `NET_REALTIME_OUTPUT_TORQUE_SLEW_NM_S` | `10.0` | 力矩随时间的变化率上限（缓升，防突变） |
| `NET_REALTIME_IDLE_KP` / `IDLE_KD` | `0.0` / `0.05` | 空闲（解耦/超时）时保留的小阻尼，位置环放开 |

### 4.4 重力补偿（`motor_conf.h`）

| 宏 | 值 | 含义 |
|---|---:|---|
| `ROBSTRIDE_GRAVITY_COMPENSATION_ENABLED` | `1` | 是否启用重力补偿 |
| `ROBSTRIDE_GRAVITY_COMPENSATION_LIMIT_NM` | `0.50` | 单轴重力补偿力矩限幅 |
| `ROBSTRIDE_GRAVITY_SCALE_J1/J2/J3` | `1.0/2.0/1.0` | 实测校正系数（J2 用了 2.0，因为 CAD 质量属性和传动比需要修正） |
| `ROBSTRIDE_GRAVITY_URDF_DIRECTION_J*` | `1.0` | 关节角从应用坐标映射到 URDF 坐标的方向 |
| `ROBSTRIDE_GRAVITY_URDF_OFFSET_J*_RAD` | `0.0` | 对应的零位偏移 |

### 4.5 如何理解这些参数

- **`Kp` 越大越"硬"**：跟随越紧，但越容易顶、越容易抖。
- **`Kd` 越大越"稳"**：阻尼吸收振荡，但太大响应变慢、发黏。
- **`TORQUE_LIMIT` 是安全底线**：决定"最多出多大力"，直接决定会不会伤人/撞坏东西。调参时**先定限幅，再调刚度**。
- **`SLEW` 是缓升**：防止力矩一步跳变。太小响应慢，太大失去保护意义。
- **`MAX_ERROR / MAX_SPEED / UNSTABLE_TIMEOUT` 是"失稳保护"**：一旦长期偏离过大就**主动解耦**，而不是让两边互相越顶越猛。这是防"长跑自激"的关键。

> ⚠️ 这些值是**针对这台无负载三自由度臂**标定的。换臂、换载荷、换传动都要**重新标定**（尤其 `SCALE_J2` 和重力补偿）。调参顺序建议：`TORQUE_LIMIT → SLEW → Kd → Kp → 重力补偿 scale`。

---

## 5. 一句话总结

- **直接加电流** = 纯力，**无柔顺**；**位控** = 只认位置，**碰了硬顶**。
- **阻抗** = 位姿→力（能发力矩就能做）；**导纳** = 力→位姿（要有力传感器）。
- **阻抗/导纳 = 弹簧-阻尼模型**，是"柔顺控制"，介于力控和位控之间。
- 我们项目用**虚拟弹簧-阻尼 + 虚拟墙 + 重力补偿 + 总限幅/缓升**实现了柔顺的主从联动。
- 参数先调安全限幅，再调刚度/阻尼；换臂必须重新标定。
