# 机器人运动学（基础）

> 仅涉及最基础知识点,用于快速入门：坐标系的建立、D-H参数表、正运动学（FK）和逆运动学（IK）。

## 0. 正逆运动学

- **正运动学（Forward Kinematics, FK）**：知关节角度求解末端位置
  控制电机时就是不断改角度，算末端会到哪。

- **逆运动学（Inverse Kinematics, IK）**：已知想要的末端位置/姿态，反推出每个关节该转多少度。
  这是想让末端到那个点必须做的。

两者是相反的过程。IK 麻烦得多，因为：

1. 一个末端位置可能对应多组关节角（多解）；
2. 可能无解（超出工作空间）；
3. 一般难解（非线性、三角方程）。

一般机器人偏向解析解设计——结构能写出解析解，就不用去跑数值迭代了。

## 1. 建立坐标系

给每个连杆绑一个坐标系，然后描述相邻坐标系之间的关系。

最常见的是 D-H 表示法。它要求每个坐标系 `i` 的 `z` 轴沿着关节 `i` 的**旋转轴**。

这是整套约定里唯一不能妥协的规则。

剩下可以约定x或者y有都尽可能的 各自 相同 的 指向 一个 方向。

可以按照下面方式建

### 1.1 找关节轴

每个转动关节有一条旋转轴。从基座往末端数，第 1、2、3...根轴就是 `z0, z1, z2...`。

### 1.2 定原点

坐标系 `i` 的原点放在**关节轴 `z_i` 与相邻轴 `z_{i-1}` 的公垂线**与 `z_i` 的交点。

- 如果两根轴相交，原点就放在交点。
- 如果两根轴平行，公垂线随便取，一般取对结构最直观的位置。

### 1.3 定坐标轴方向（D-H 的核心规则）

设坐标系 `i` 的轴为 `x_i, y_i, z_i`：

- `z_i`：沿关节 `i` 的旋转轴（固定规则）。
- `x_i`：沿 `z_{i-1}` 到 `z_i` 的公垂线方向。
- `y_i`：由右手定则补全：`y_i = z_i × x_i`。

### 1.4 基座坐标系（frame 0）

`z0` 沿关节 1 的旋转轴。

- 原点一般放在基座底面中心或关节 1 的轴线上，直观为好。
- `x0, y0`随意，直观为好。
- 姿态计算以基座坐标系为准。

### 1.5 末端坐标系（tool frame）

- 建在末端执行器上，`z` 一般沿夹爪方向。

## 2. D-H 参数表

D-H 用四个参数描述相邻坐标系 `i-1` 到 `i` 的变换：

| 符号 | 名字 | 含义 | 怎么确定 |
|---|---|---|---|
| `θ_i` | 关节角 | 绕 `z_{i-1}` 的转角（转动关节的变量） | 变量，就是我们的 `q` |
| `d_i` | 连杆偏置 | 沿 `z_{i-1}` 的距离 | 量相邻两轴的沿轴距离 |
| `a_i` | 连杆长度 | 沿 `x_i` 的距离（公垂线长度） | 量 `z_{i-1}` 到 `z_i` 的垂直距离 |
| `α_i` | 连杆扭角 | 绕 `x_i` 的转角（从 `z_{i-1}` 转到 `z_i`） | 量两轴之间的夹角 |

### 2.1 填表

- `θ` 是转动关节，`d, a, α`是由机械结构决定的常量。
- `α_i` 是绕 `x_i` 把 `z_{i-1}` 转到 `z_i` 的角，不是绕某个轴的简单夹角，要看正负。

## 5. 正运动学（FK）怎么做

### 5.1 相邻坐标系的变换矩阵

在 D-H 约定下，从坐标系 `i-1` 到 `i` 的齐次变换矩阵（**修正 D-H** 版本）是：

```
T_i = Rz(θ_i) * Transz(d_i) * Transx(a_i) * Rx(α_i)
```

展开成 4×4 矩阵（`cθ=cosθ, sθ=sinθ`，余类推）：

```
        | cθ   -sθ·cα    sθ·sα    a·cθ  |
T_i  =  | sθ    cθ·cα   -cθ·sα    a·sθ  |
        | 0      sα       cα      d     |
        | 0      0        0       1     |
```

> 如果用的是**标准 D-H**，矩阵形式不同（`T = Rz(θ)·Transz(d)·Transx(a)·Rx(α)` 但乘法顺序/参数定义略有差异）。**务必和你的教材/URDF 保持一致。**

### 5.2 从基座到末端连乘

末端坐标系 `n` 相对基座 `0` 的位姿：

```
T_0n = T_1 · T_2 · T_3 · ... · T_n
```

对三自由度臂就是 `T_03 = T_1(q1) · T_2(q2) · T_3(q3)`。把每个 `q` 代进去，乘出来就是末端位置 `(px, py, pz)` 和姿态（旋转矩阵）。

**这就是 FK：给定 `q`，一顿矩阵乘法，得到末端位姿。** 计算机里就是循环乘 4×4 矩阵，很机械。

### 5.3 和本项目的关联

我们项目里其实**没有单独写一个"FK 函数"**——因为我们是"关节空间控制"，直接给电机发关节角，不需要正向算末端。但 `gravity_compensation.cpp` 里**隐含做了 FK**：它把每个关节轴、连杆原点变换到基座系，得到 `link_pose[i]`（就是 `T_0i`），再用这些位姿去算重力补偿力矩。

所以你要是想在本项目里加 FK，照 `gravity_compensation.cpp` 的 `compose()` + `axis_angle()` 那套写一个返回末端位姿的函数就行——它已经在做矩阵连乘了，只是把结果用在了重力补偿上。

## 6. 逆运动学（IK）怎么做

### 6.1 两种思路

| 方法 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **解析解（封闭解）** | 快、精确、无迭代、可穷举所有解 | 要推导，结构复杂时推不出来 | 结构规整、关节少的臂 |
| **数值解（迭代）** | 通用，啥臂都行 | 慢、可能收敛到局部解、要选初值 | 冗余/复杂臂、实时性不敏感 |

**我们这台 3 自由度臂就是冲着"能写出解析解"去设计的**（结构简单、无冗余），所以下面重点讲解析解，不碰数值迭代。

### 6.2 思路：先解转台角，再化平面二连杆

对"转台 + 两个俯仰关节"的臂，解析解非常好拆：

1. **解 `q1`（转台角）**：
   给的目标是末端在基座系的位置 `(px, py, pz)`。转台只影响水平投影：
   ```
   q1 = atan2(py, px)        // 末端在水平面的方位角
   ```
   注意：这只在"末端在转台轴正上方投影"有意义，所以要**先把目标点投影到水平面**。

2. **降成平面二连杆问题**：
   转动 `q1` 之后，整个臂在一个**竖直平面**里（这个平面包含转台轴和目标点）。在平面里解 `q2, q3` 就是一个标准的**两连杆平面臂 IK**（用余弦定理）：

   ```
   // 先求"有效平面距离"（把目标点从基座原点换算到肩关节原点，再投影到竖直面）
   // 简化：设肩到目标点的平面距离为 r，竖直高度为 h
   r² = (√(px²+py²) - offset_x)² + (pz - offset_z)²     // 近似
   cos(q3) = (r² - L1² - L2²) / (2·L1·L2)                // 余弦定理
   ```

3. **多解与取舍**：
   - `cos(q3)` 解出的肘角通常有**两个解**（肘朝上 / 肘朝下，即 `q3` 和 `-q3`）。
   - 肩角 `q2` 也会跟着有**两个**。
   - 所以一个末端位置可能对应 **最多 4 组 `(q1, q2, q3)`**。要挑：
     - **在关节软限位内**的（我们的限位是 ±135° = ±2.356 rad）；
     - 避开奇异点/碰撞的；
     - 靠近当前姿态、避免大幅跳变的。

4. **验证**：解出来之后再跑一次 FK，看末端是不是真的到了目标点。**一定要互相验证**，这是写 IK 最稳的流程。

> ⚠️ **注意点**：以上是"思路"，具体公式要**带真实 D-H 参数**推一遍，不能直接套。真实臂的关节轴不是全平行的、原点也不全在轴线上，`offset_x/offset_z` 这类项要从 URDF 里取真实值。

## 7. 几个经验/坑（写代码前看一眼）

1. **FK 和 IK 用同一套 D-H 参数**。很多人 FK 用一套、IK 又手推一套，结果对不上。干脆定义好 `T_i` 函数，FK 用它，IK 也用它。
2. **角度单位统一**。代码里统一用弧度（rad），换算到度（deg）只在显示时做。我们的 `motor_conf.h` 全部是 rad。
3. **先解决"电机读数 ↔ 关节角"映射**，再谈 FK/IK。`direction` 和 `zero_offset` 没对上，几何算得再对也是错的。
4. **解析解要考虑"末端姿态"**。上面只讲了位置 IK。如果还要求末端朝向（比如夹爪保持某个姿态），就要再解姿态部分，三自由度臂往往不够自由度，需要 6 自由度腕部结构。我们的臂只做位置级的末端控制，所以够用。
5. **软限位不是 IK 的一部分，但 IK 的结果必须过软限位**。超过 ±135° 的关节角不能下发给电机，否则撞到限位。`RobStride_App_SetTargets` 里就有 `clampf(angle, min, max)`。

## 8. 一句话总结

- **建坐标系**：每个关节 `z` 轴沿旋转轴，`x` 沿公垂线，`y` 右手补全。
- **列 D-H 表**：`θ, d, a, α`，`θ` 是变量其余是常量，注意用标准还是修正 D-H。
- **FK**：相邻变换矩阵连乘 `T_03 = T1·T2·T3`，给 `q` 得末端位姿。
- **IK**：先解转台角投影，再化平面二连杆用余弦定理，注意多解、限位、用 FK 回代验证。
- 我们这台 3 自由度臂**结构规整、偏解析解**，很适合当入门案例；真实参数以 SolidWorks/URDF 为准。
